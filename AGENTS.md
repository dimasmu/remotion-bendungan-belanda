# Repository Agent Instructions

When creating, editing, reviewing, or debugging any Remotion composition or scene in this repository:

1. Read and follow `.agents/skills/remotion-documentary/SKILL.md` before changing code.
2. Work on one scene at a time unless the user explicitly asks for a full-project refactor.
3. Inspect the current package versions, registered composition, scene timeline, and relevant shared components before editing.
4. Preserve the composition ID, canvas dimensions, FPS, total duration, and unrelated scenes unless the user explicitly approves a change.
5. Treat a successful commit as source-control success only. Never claim that the scene is built, rendered, or visually verified unless those checks were actually performed.
6. Do not merge iterative scene work into `main` without explicit approval.

The Remotion skill contains the required workflow, design rules, animation constraints, QA checklist, commands, and official documentation links.
