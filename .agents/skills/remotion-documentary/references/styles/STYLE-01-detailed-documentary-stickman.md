# Detailed Documentary Stickman — STYLE-01

## Purpose and visual identity
A clean, expressive 2D documentary illustration system built around simple stickman or simplified human figures, readable silhouettes, and carefully illustrated environments. Characters remain graphic and economical; environments and important mechanisms may carry more detail. The result should feel like a coherent illustrated documentary, not generic clip-art.

## Character construction
- Head: simple rounded or softly angular shape; lock one head shape and head-to-body ratio per project.
- Face: minimal dot/oval eyes, controlled brows, simple mouth; expressions are readable at video scale.
- Body: narrow torso, clear shoulder/hip landmarks, simple limbs with consistent joint logic.
- Hands/feet: simplified mitten, line-hand or block-hand design; choose one system and keep it.
- Clothing: broad readable silhouettes; folds and seams only when narratively useful.
- Distinguishing features: hats, hair, uniform, tools and props must be deliberately assigned and repeat exactly.
- Character variants: create only when script/scene analysis requires a distinct role, period, age, costume or crowd type.

## Line, color and rendering
Use a stable dark outline (typically warm charcoal rather than pure black), consistent stroke hierarchy, flat fills, restrained cel shading and subtle paper/grain texture only if approved. Define exact HEX palette in project/style/PALETTE.md. Avoid gradients that weaken shape clarity.

## Environments and objects
Illustrate environments with more structural detail than characters where useful: buildings, landscapes, machinery and maps use clear geometry, layered depth and selective texture. Important objects need stable silhouettes and component relationships. Use cutaways/exploded views for mechanisms.

## Layout and camera
Prefer readable 2D staging, clear foreground/midground/background layers, modest parallax and deliberate camera pans/zooms. Maintain consistent horizon, perspective and scale within a sequence. Avoid perspective shifts that make characters appear to change size.

## Animation behavior
Use simple pose changes, limb pivots, holds, squash/stretch sparingly, and clear anticipation. Characters should not morph between poses. For cut-out animation, separate head, torso, upper/lower limbs, hands and props only when needed by the rig.

## Character sheet requirements
One sheet per needed character, never a group lineup. Show only the views/expressions/actions required for that character. Keep front/three-quarter/side/back as the default turnaround set for recurring characters; optional rows are conditional, not mandatory. Full figure visible, consistent scale, plain background, no overlaps.

## Prompt constraints
Explicitly name the approved palette HEX values, outline thickness/style, head/body ratio, face grammar, clothing silhouette, shading and texture. Forbid extra characters, unapproved props, style drift and text unless labels are requested.
