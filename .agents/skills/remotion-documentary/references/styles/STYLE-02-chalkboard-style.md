# STYLE-02 — Chalkboard Style

## Visual identity
An educational hand-drawn explanation on a dark green, charcoal or black chalkboard. Drawings resemble white and colored chalk: slightly dusty, imperfect and tactile, while remaining legible at video size.

## Construction rules
- Lock board color, chalk grain, stroke width and chalk color set.
- Use hand-drawn outlines, simple cross-sections, arrows, labels, diagrams and sequential sketches.
- Chalk strokes should show subtle grain and broken edges, not a digital vector-perfect line.
- Use a restrained accent set (for example muted yellow, blue, pink and green) with white as the primary drawing color.
- Characters, if needed, are simplified chalk illustrations and must match the same stroke language.

## Camera and motion
Use overhead/straight-on board framing or a deliberate close-up. Animate chalk strokes with path reveals, erase-and-redraw transitions, diagram assembly, underlines and pointer movements. Use chalk dust sparingly. Keep the board stable unless a motivated camera move is planned.

## Asset prompt requirements
Describe board material, chalk texture, stroke hierarchy, diagram subject and exact accent palette. Request clear negative space for labels to be added in Remotion. Avoid generated pseudo-text; add accurate labels as editable Remotion typography.

## Avoid
Glossy 3D objects, photorealistic classroom scenes, neon glow, overly clean vector lines, illegible handwriting and excessive chalk dust.
