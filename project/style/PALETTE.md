# Palette — Enigma Shorts

Status: APPROVED. Style: STYLE-03 Glow Sketch.

| Name | HEX | Usage |
| --- | --- | --- |
| Void | `#070A0F` | Main background |
| Panel | `#0E141C` | Panels, chips, caption backings |
| Construction | `#1B2733` | Faint grid, leader lines (20–30% opacity) |
| Ice Line | `#7FE7FF` | Primary stroke, active signal path |
| Ice Dim | `#3E8FB0` | Secondary stroke |
| Rotor Violet | `#A78BFF` | Rotor wiring, 1932 timeline node |
| Lamp Amber | `#FFC46B` | Lit lamp, surviving Bombe candidate |
| Alert Red | `#FF5C5C` | Contradiction, discarded candidate |
| Signal Green | `#66F2A5` | Readable state (reserved) |
| Text Primary | `#EAF4F8` | Headlines, numbers |
| Text Muted | `#8CA0AE` | Sub-labels, units, source line |

Ratio per scene: about 80% Void/Panel, 15% Ice, 5% or less accent.

Contrast on Void: Text Primary ~19:1, Text Muted ~7.4:1, Ice Line ~14:1, Lamp Amber ~13:1, Alert Red ~6.3:1.

Forbidden: rainbow gradients on one stroke, bloom that hides labels, any colour not listed.
